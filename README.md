## Photographs

User-supplied photographs are stored under images/ and displayed at their original aspect ratios on life.html. Click a photo to view the full-size image. Captions use the locations provided by the user.

## GitHub Pages

Upload all HTML files, style.css, and .nojekyll to the root of Shidabot.github.io. In Settings → Pages, choose Deploy from a branch, main, / (root). Check existing repository content before replacing it.

Official guide: https://docs.github.com/en/pages/quickstart
